# Design Garage Launch Kit

## One-line description

Design Garage is a fast, high-contrast directory for discovering interface resources, frontend tools, and visual references without losing time to noisy search results.

## Short launch post

I built **Design Garage**, a curated resource directory for people designing and shipping interfaces. Search by name, technology, or a resource ID such as `resource 001`; filter by category and stack; switch between Grid and List views; and open or copy useful tools quickly. The project is open source, responsive, and built with accessibility checks in CI. Try the live demo, and if it improves your workflow, consider starring the repository to support ongoing curation.

## Community post angle

Show one specific use case rather than describing every feature. For example: “I wanted a faster way to compare React, Tailwind, and design-reference resources without collecting hundreds of bookmarks. Design Garage keeps the browsing flow public and compact.” Include a short screen recording of search, filtering, Grid/List switching, and a resource visit.

## Demo checklist

Use a 30–45 second recording. Start on the landing page, enter the Directory, search for `resource 001`, apply one technology filter, switch Grid/List view on mobile width, toggle the theme once, and open one resource. End on the repository URL and live-demo URL.
