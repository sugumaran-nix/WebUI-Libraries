# Contributing to Design Garage

Design Garage is a focused, public directory for interface resources and frontend tools. Contributions should improve discovery, accuracy, accessibility, or the practical quality of the browsing experience.

## Before opening an issue or pull request

Search the current directory and open issues first so that duplicate resources and duplicate work do not accumulate. For resource additions, confirm that the website is live, publicly accessible, relevant to interface design or frontend work, and not already represented under another name.

## Resource additions

Include the resource name, canonical URL, concise description, most appropriate category, and relevant technology tags. Use factual language that describes what the resource provides. Do not submit referral links, copied marketing claims, or resources that require an account merely to view their core value.

## Product improvements

For interface, accessibility, performance, or responsive improvements, describe the current behavior, intended behavior, affected route, browser or device size, and a reproducible path. Keep the public landing marquee structurally unchanged unless a maintainer has explicitly requested a change.

## Pull request standard

Keep changes focused, preserve the Design Garage visual system, and include the relevant verification results. For frontend work, run the production build and the repository browser and accessibility checks. For catalog changes, ensure the resource remains searchable and correctly categorized.

## Community expectations

Be constructive, specific, and respectful. Design Garage values useful curation over volume, clear writing over hype, and accessible product decisions over visual novelty alone.
